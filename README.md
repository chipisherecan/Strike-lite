# Strike Lite

A lightweight, CS-style 5v5 bomb-defusal shooter that runs in your web browser.
It's built for low-end PCs (8 GB RAM, weak GPU, Intel i5). Everything (maps, textures,
models, sounds) is generated in code, so there's nothing big to download.

## Launcher (for players)

Download **`StrikeLiteLauncher.exe`** from the latest GitHub release and run it; nothing else is needed.
It downloads the game (with its own copy of Node.js) into `%LOCALAPPDATA%\StrikeLite`, and every time it opens it
checks for a newer release, updates the game and itself, and verifies each download's checksum. Maps saved in the
editor are kept across updates. Windows may warn about an unknown publisher because the exe isn't code-signed
(More info > Run anyway).

**Playing with friends online:** everyone clicks **Install Radmin VPN** in the launcher (the official, unmodified
installer is built in, and you accept Radmin's own license agreement when it runs). Join the same Radmin network. The
host clicks **Play / Host a game** and shares the address shown at the bottom; friends type it under **Join a friend**.
Allow Node.js through Windows Firewall when asked, on both private and public networks.

## Publishing a new version (for the developer)

The repo must be public, so launchers can read releases without a login. Then:

```
git tag v1.0.1
git push origin v1.0.1
```

`.github/workflows/release.yml` builds and publishes the release automatically. Change `launcher/launcher-version.txt`
(raise the number) only when `launcher/Launcher.cs` changes; players then download the new launcher too.
To move to a newer Radmin VPN, update the version in `tools/build-release.ps1` and the hash in `launcher/radmin.sha256`.

## Running from source

1. Install **Node.js** (LTS) from https://nodejs.org if you don't have it.
2. Double-click **`start.bat`**. The first run installs two small libraries.
3. Your browser opens at `http://localhost:3000`. Enter a name, then **Create lobby**.

Keep the black server window open while you play.

## Playing with friends (lobbies)

The PC that runs `start.bat` is the **host**. The server window shows lines like:

```
Friends connect to:   http://192.168.1.25:3000
```

- **Same Wi-Fi/house (LAN):** friends open that address in their browser, click **Find a lobby**, and join yours.
  If it won't connect, allow Node.js through Windows Firewall (Windows usually asks the first time; choose "Private networks").
- **Over the internet:** the easiest way is a free virtual LAN app like **Tailscale**, **ZeroTier** or **Radmin VPN**.
  Everyone installs it and joins the same network, then friends use the host's address from that app, for example `http://100.x.x.x:3000`.
  (Or forward TCP port 3000 on your router to the host PC and share your public IP.)

Lobbies can have a password, 0–9 bots (Easy/Normal/Hard), and a match length of 8, 16 or 24 rounds.
The lobby host can change the map, the bot count and the difficulty, or restart the match from the Esc menu.

## Maps

The three most-played competitive maps at real scale. The layouts (walls, floor heights, boxes,
bombsites and spawns) are traced from the official CS2 radar overviews by `tools/trace-radar.js`,
which downloads the radar images into memory and writes only the resulting grid to `shared/mapdata/`.
Geometry, textures and models are generated by the game. This is a personal fan project; the map
layouts belong to Valve, so don't publish or sell it.

| Map     | Areas |
|---------|-------|
| Dust II | T spawn, outside long, long doors, long A, pit, A site, catwalk/short, mid, mid doors, CT mid, upper/lower tunnels, B site, B doors, B window |
| Mirage  | T spawn, top mid, palace, A ramp, A site, jungle, connector, window room, CT, B apartments, short, B site, market |
| Inferno | T spawn, banana, B site, construction, CT, library, A site, apartments, balcony, boiler, second mid, mid, pit |

## How it's built (the GoldSrc / CS 1.6 way)

Nothing is taken from CS 1.6 or CS2. The game copies how GoldSrc builds and draws things:

- **Maps are brushes.** Every wall, floor, ramp, box and roof is a solid convex brush, like a map made in Hammer.
  The traced layouts are converted into brushes automatically; the map editor edits brushes directly.
- **Collision like GoldSrc player movement.** The player box is swept through the brushes (each brush plane pushed out
  by the box size, like GoldSrc "hulls"), sliding along walls, stepping up 0.45 m stairs and walking up slopes.
- **Lightmaps.** When a map loads, hidden brush faces are clipped away (like the map compiler's CSG step), and every
  visible face gets a lightmap: sun shadows, sky light, bounce light and point lights (lamps), packed into one texture.
  This runs once (a few seconds) and is then cached in your browser, so it costs nothing while playing.
- **Skybox.** A painted six-sided sky with clouds and distant hills.
- **Characters.** One skinned mesh on a 20-bone skeleton per player, every vertex attached to one bone, with a painted
  texture skin. Keyframed animation (run, walk, crouch, jump, aim pitch, shooting kick). Players are lit by the
  lightmap under their feet, so they get darker in tunnels and shadows.
- **View models.** Hands with fingers and the weapon are one rig with its own field of view, animated by sequences:
  draw, idle, shoot (slide/bolt kick) and reload (magazine out, new magazine in, charge).

## Map editor

Open **Map editor** in the main menu and enter the password. It's a top-down brush editor, like Hammer:

- The real CS2 radar can be shown underneath (slider) to line things up with the original map.
- **Select** (click / Shift+click / drag a box), drag to move, drag the yellow squares to resize, arrow keys and
  Page Up/Down to nudge. **Box** makes walls, floors/platforms, crates and roofs. **Ramp** makes slopes and stairs.
  **Zones** sets bombsites and spawns. **Decor** places lamps, palms, trees, doors and awnings. **Light** adds baked lights.
- The properties panel sets exact heights, positions, textures (top/side/bottom) and flags (wall, roof, box, player clip).
- **3D view** lets you fly around the map you're editing. **Check** makes sure both teams can reach both bombsites.
- **Save map** stores it in `shared/mapdata/edits.js`, and every new lobby uses it (press F5 to reload the game after saving).
  **Reset to original** brings back the traced map. Saving only works on the PC that runs the server.
- Players step up 0.45 m and jump about 0.95 m, and need 2 m of headroom.

## Gameplay

- Terrorists plant the C4 at site **A** or **B**. Counter-Terrorists defend and defuse it.
- Rounds last 1:55, with a 10-second buy freeze at the start. The bomb timer is 40 seconds. Defusing takes 10 seconds, or 5 with a kit.
- Money works like CS: $800 to start, a bonus for winning rounds, a loss bonus that grows, and kill rewards (SMGs $600, AWP $100, knife $1500).
- Weapons: Glock, USP-S, P250, Desert Eagle, MAC-10, MP9, Galil, FAMAS, AK-47, M4A4, AWP, knife, HE, flashbang and smoke grenades.
- Spray patterns, moving inaccuracy, headshots (×4), kevlar and helmet armor, and slowing when you get shot.
- Teams swap sides at halftime.

## If the game closes while playing

Crouch is **Ctrl**, and **Ctrl+W** is the browser's "close tab" shortcut. The game now goes fullscreen when you
click in and locks the keyboard (Chrome/Edge), so Ctrl+W goes to the game instead. Every browser also asks
"Leave site?" before closing mid-match. If you turn fullscreen off in Settings, use **C** to crouch instead.

If the server window shows an error, it is also saved to `server-errors.log`. Send that file if something breaks.

## If it runs slowly

Open **Settings** and lower the **Render scale** (0.5 is a big speed-up) and the **View distance**.
Turn on **Show FPS** to see the effect. Chrome or Edge usually run it best.

## Files

- `server.js`: web server, lobbies, rounds, economy, bomb and bot AI
- `shared/`: maps, physics/collision and weapon stats (used by both the server and the game)
- `public/`: the game in the browser (Three.js rendering, HUD, menus, sound)
- `shared/brush.js`: brushes, box traces and slide/step movement; `shared/nav.js`: bot navigation on brush maps
- `shared/maps.js`: map definitions, grid-to-brush conversion, and the hand-made roofs/materials/decor per map
- `public/js/world.js`: CSG face clipping, lightmap baking, skybox, decorations; `public/js/models.js`: skinned
  characters, weapons and view models; `public/js/editor.js`: the map editor
- `tools/trace-radar.js`: re-traces the maps from the CS2 radar images (`node tools/trace-radar.js`)
- `tools/walk-test.js`: walks every spawn-to-bombsite route on every map and reports where it gets stuck (`npm run check`)
- `tools/bot-test.js`: headless bot match smoke test (`node tools/bot-test.js 60 dust2`, with the server running).
  Start the server with `BOTDEBUG=1` to print what each bot is doing.
